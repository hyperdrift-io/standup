## Story and implementation

The maintainer returns to projects that still stand. Maya has already offered a
fix. The route follows that contribution to the moment their attention can help,
then offers a review that fits one evening. This sample is illustrative; real
briefs retain actual people, evidence, actions, estimates and scan limitations.

Native details at all three marked stations reveal the story. Hover or focus
opens context; click/tap pins or closes it; Escape dismisses it. The corresponding
outgoing coral segment deepens while competing routes recede. Mobile uses a
continuous vertical route with the same disclosures in normal flow. Native click
and keyboard disclosure still work without JavaScript. Reduced motion removes
transitions. The final station links back to the actual handle form.

The composition follows the approved image: broad centered promise, immediate
pill form, large open interval, irregular intersecting routes and filled markers.
Self-hosted Figtree is a licensed interpretation, not an identified source font.
SVG paths are native geometry; all text remains live. CSS is the complete cascade;
ScreenCraft's exported declarations are only a component mapping aid.

## Accuracy review

The first comparison exposed material compression: small wordmark/title/form,
shallow evenly spaced waves, and displaced standing copy. These were corrected.
A second comparison confirmed the broad hero composition and highlighted remaining
supporting-path drift; slate entry, sage ending and lower paths were corrected.
The review is not a pixel-fidelity percentage or a claim of exact font matching.

Intentional adaptations: distinct interactive story stations replace duplicated
Maya/Next step labels; accessible darker action fill; complete public/read-only
copy and audit. Audit and footer extend the page beyond the source desktop crop.
Mobile uses a readable continuous route rather than fragmented horizontal crops.

## Browser evidence

Desktop inspected at 1637x1421, mobile at 390px. All three stations are native
focusable disclosures. Keyboard focus opens context; Escape closes it and keeps
visible focus. Touch opens/closes the same content. A 320px viewport with 200%
root text initially exposed overflow; wrapping was corrected and scroll/client
widths now both equal 320px. This is text scaling, not OS/browser zoom certification.
The real yannvr scan returned three actions and 14 audit entries; the reading
region used one native view transition. No automated test suite was introduced.

Evidence: root clear-line/review/ and packet/comparisons/. Static comparisons do
not validate behavior; manual inspection does not certify every browser or OS.

## Laptop-height correction — 2026-09-11

The 650px route and tall hero pushed the lower line outside ordinary laptop
viewports. The desktop layout now adapts to viewport height below 1100px, using
proportional station positions, a shared route-height variable, and tighter hero
spacing. The lowest pale path also has stronger contrast. The full route and
footer were manually verified inside 1440x900 and 1366x768 viewports, with no
horizontal overflow at 1366px. The tall reference composition remains unchanged.
